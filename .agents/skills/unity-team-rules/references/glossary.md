# Glossary

- Tycoon loop: demand -> production/service -> revenue -> upgrade -> stronger throughput
- Bottleneck: the current limiting step reducing overall efficiency
- Story system: episode, line, module, runtime, presentation layers
- SO: ScriptableObject
- Event channel SO: ScriptableObject-based event relay used for loose coupling
- Isometric: 2D visual presentation with depth illusion and strict readability needs
- Content-safe change: a change that does not silently break inspector references or authoring flow
