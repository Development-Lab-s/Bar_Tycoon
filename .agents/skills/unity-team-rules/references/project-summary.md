# Project Summary

- Genre: 2D isometric subculture tycoon game
- Core fantasy: grow and optimize a stylish venue while building attachment to characters and story
- Target feel: clean, readable, charming, efficient, replayable
- Primary platform assumption: PC development environment with mobile-minded UI/layout decisions
- Main pillars:
  - readable tycoon loop
  - character appeal and progression
  - story and unlock pacing
  - maintainable Unity architecture
